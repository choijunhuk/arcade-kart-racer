# Phase 9 UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver the complete Phase 9 menu, settings, HUD, pause, results, data-driven selection, and gamepad-only race flow defined by `KART_RACING_DEV_PROMPT.md` section 18 and Phase 9.

**Architecture:** Keep scene flow in small UI controllers that write selections through `GameState`, construct `RaceConfig` through a pure builder, and enter gameplay only through `GameState.change_scene`. Keep HUD, minimap, pause, and results as presentation observers of EventBus and read-only race APIs; keep persistence in `SettingsManager` and `SaveManager`.

**Tech Stack:** Godot 4.7, statically typed GDScript, `.tscn` scenes, `.tres` resources, GUT 9.6.1, headless import/parse/validation.

**Spec:** `KART_RACING_DEV_PROMPT.md` sections 2.2, 18, 20-24, and 29

## Global Constraints

- Work only on checked-out branch `phase/09-ui`; do not push or switch branches.
- Use one implementer and no sub-agents.
- Run Godot only with `--headless` for automated gates and with `HOME="$PWD/.tmp-home"`.
- After adding Godot files, run `/opt/homebrew/bin/godot --headless --path . --import` and commit generated `*.uid` files.
- Never add a `[network]` or TLS section to `project.godot`.
- Keep all GDScript statically typed and every `.gd` file at or below 400 lines.
- Use one shared `Theme`; support keyboard, gamepad, and mouse, with explicit initial focus and directional focus neighbors.
- Preserve Phase 8 Tween feedback and keep all HUD elements outside the right-anchored DebugOverlay area.
- Add no dependency. If an official-source font cannot be downloaded, use Godot's default font and record Phase 13 replacement debt.
- Commit small verified slices with `git commit -m` and Lore trailers.
