# Fonts — Phase 19 visual identity

**Chakra Petch** (Bold Italic, Bold, SemiBold) by Cadson Demak / The Chakra Petch
Project Authors, licensed under the SIL Open Font License 1.1 (`OFL.txt`, shipped
alongside the font files as the licence requires).

Source: https://github.com/google/fonts/tree/e44c4b011a820c2cbe2fd2cfa8052037d7edb571/ofl/chakrapetch
(upstream: https://github.com/m4rc1e/Chakra-Petch). Files are unmodified.

Usage (all wired through `ui/theme/default_theme.tres`):
- `ChakraPetch-BoldItalic.ttf` — display face: titles, buttons, HUD numbers.
- `ChakraPetch-Bold.ttf` — letter-spaced captions / HUD labels.
- `ChakraPetch-SemiBold.ttf` — default UI body text.

Glyphs outside the font (e.g. ★ ▶) fall back to Godot's system font fallback.
